# 👩‍💻 My Portfolio

A **personal portfolio website** built with vanilla HTML, CSS, and JavaScript — showcasing who I am, my work, and my journey as a developer.

## ✨ Features

- 🖼️ **Personal branding** — custom photos and identity
- 🎨 **Hand-crafted CSS** — no frameworks, pure craftsmanship
- ⚡ **Vanilla JS interactions**

## 🧱 Tech Stack

- HTML5
- CSS3
- JavaScript (ES6+)

## 🚀 Getting Started

```bash
git clone https://github.com/Tech-Guru19/My-porfolio.git
cd My-porfolio
# open index.html in your browser, or run a local server
python3 -m http.server 8080
```
