# Personal Portfolio

## Overview

A personal portfolio website built with vanilla HTML, CSS, and JavaScript. The site showcases professional identity, work samples, and the developer journey.

## Key Features

- **Personal branding:** Custom photography and identity presentation
- **Hand-crafted styling:** Pure CSS without frameworks
- **Interactive elements:** Vanilla JavaScript interactions

## Technology Stack

- HTML5
- CSS3
- JavaScript (ES6+)

## Getting Started

```bash
git clone https://github.com/Tech-Guru19/My-porfolio.git
cd My-porfolio
# Open index.html directly, or serve locally
python3 -m http.server 8080
```
